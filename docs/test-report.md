## テスト中に見つけて直した不具合

- 同じミリ秒に連続保存すると履歴の前後が曖昧になり、上限整理で新しい版を消すおそれがあった → 更新日時を必ず前回より大きくするよう修正
- 入力欄の見出しが選択肢の文字まで含めて読み上げられる構造だった（アクセシビリティ）→ 見出しと入力欄を id で関連付ける方式に修正
- 下部タブとカテゴリー選択欄が同じ名前「カテゴリー」で区別できなかった → タブを「カテゴリーのタブ」に変更
- 自動で付いたメモのタイトルが一覧の抜粋にも重複表示されていた → 抜粋から除外

## iPhone実機での確認手順（おすすめ）

1. ホーム画面に追加して起動 → 案内が出る
2. クイックメモを保存 → アプリを完全に終了して再起動 → 残っている
3. OCを作り、写真ライブラリから数枚（HEIC含む）・透過PNGを追加 → 保存 → 詳細で拡大表示
4. 機内モードで起動 → 閲覧・編集・保存
5. バックアップ → 共有シート →「"ファイル"に保存」→ iCloud Drive → 「ファイル」アプリで存在を確認
6. Safariで同じURLを開き（別の保存場所）、そのZIPを復元 → 画像まで戻るか
7. 設定 → 「端末の保存領域」の保護（永続化）がどう表示されるか
8. GitHubから一括登録（実際のAPI）
